# OneTome

**One book. Finish it.**

Local-first Flutter PDF reader that enforces one active book at a time.

## Features (local-first)

- Import a single PDF
- Strict one-book rule
- Page progress tracking
- "Done for today" lock
- Day / night modes
- History of finished books
- Provider state management
- Liquid glass style UI

## Setup

```bash
flutter pub get
flutter run
```

Requires Flutter 3.16+.
